# Лабораторная работа

Программа обрабатывает набор данных о товарах из файлов CSV, JSON и XML, запускает локальный REST API и проверяет получение данных через Selenium.

## Требования

- Python 3.10 или новее;
- Google Chrome для сценариев с Selenium;
- установленный `pip`.

## Установка

Откройте терминал в папке проекта и выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Если PowerShell не разрешает активацию окружения, можно запускать интерпретатор напрямую:

```powershell
.\.venv\Scripts\python.exe main.py
```

## Запуск программы

```powershell
python main.py
```

После запуска появится меню:

```text
1. Нормализовать данные из CSV, JSON и XML
2. Выполнить сценарий CRUD через REST API
3. Выполнить сценарий с Selenium и сохранить таблицу
4. Вывести статистику
0. Выход
```

Введите номер пункта и нажмите Enter.

### Пункт 1. Нормализация данных

Перед обработкой программа предлагает выбрать разделитель CSV-файла: запятую, точку с запятой или табуляцию.

Программа читает файлы из `data/raw/`:

- `items.csv`;
- `items.json`;
- `items.xml`.

Затем она приводит столбцы к общей схеме, преобразует типы данных, удаляет дубликаты и разрешает совпадения по `id`. При совпадении выбирается запись с наиболее поздним `updated_at`; при одинаковой дате приоритет имеют CSV, JSON и XML.

Результаты сохраняются в `data/processed/`:

- `items_normalized.csv`;
- `items_normalized.json`;
- `items_normalized.xml`.

### Пункт 2. REST API и CRUD

Программа автоматически запускает локальный backend на `http://127.0.0.1:8000`, выполняет операции создания, полной замены, частичного изменения, чтения и удаления записи, а затем останавливает backend.

Результаты запросов сохраняются в `data/processed/course_2_requests.json`.

Основные API-адреса:

- `GET /api/items` — получить все записи;
- `GET /api/items/{id}` — получить одну запись;
- `POST /api/items` — создать запись;
- `PUT /api/items/{id}` — заменить запись;
- `PATCH /api/items/{id}` — изменить отдельные поля;
- `DELETE /api/items/{id}` — удалить запись.

### Пункт 3. Selenium

Программа запускает backend и Chrome, открывает страницу `http://127.0.0.1:8000/dynamic`, загружает таблицу и фильтрует ее по категории `Category B`.

Результат сохраняется в `data/processed/selenium_items.csv`. После завершения браузер и backend закрываются автоматически.

### Пункт 4. Статистика

Пункты 1, 2 и 3 сохраняют свою статистику сразу после завершения. Пункт 4 ничего повторно не запускает: он проверяет, выполнены ли первые три пункта, и выводит уже накопленный отчет.

Если хотя бы один из первых трех пунктов еще не выполнен, программа сообщает, какой пункт нужно запустить. После выполнения всех трех сценариев сохраняются:

- `data/processed/course_4_report.csv`;
- `data/processed/course_4_report.md`.

В отчете указаны количество записей, количество уникальных `id`, время выполнения и ошибки каждого способа.

## Запуск backend отдельно

Чтобы запустить API вручную, выполните:

```powershell
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

После этого доступны:

- API: `http://127.0.0.1:8000/api/items`;
- динамическая страница: `http://127.0.0.1:8000/dynamic`;
- документация Swagger: `http://127.0.0.1:8000/docs`.

Для остановки backend нажмите `Ctrl+C`.
