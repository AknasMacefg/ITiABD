# Лабораторная работа: загрузка, JOIN и витрина данных

Проект демонстрирует загрузку данных из CSV, REST API и SQLite, проверку ключей, объединение средствами pandas и SQL, а также построение аналитической витрины.

## Структура

- `lab_2.ipynb` — основной воспроизводимый сценарий лабораторной работы;
- `src/loaders.py` — загрузка организаций, транзакций через FastAPI и городов из SQLite;
- `src/transform.py` — нормализация ключей, диагностика, pandas JOIN и построение витрины;
- `src/database.py` — загрузка DataFrame во временную SQLite и SQL JOIN/агрегации;
- `data/` — исходные данные и SQLite-база;
- `data/processed/` — `data_mart.csv` и `data_mart.parquet`;
- `results/curl_commands.txt` — команды и существенные ответы этапов A–B;
- `results/dashboard.png` — итоговая BI-визуализация.

## Запуск

```powershell
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

После запуска API откройте `lab_2.ipynb` и выполните ячейки по порядку. Ноутбук заново создаёт витрину и сохраняет CSV, Parquet и dashboard.

## Намеренные проблемные данные

- организация `org_id=10` не имеет операций;
- операция с `org_id=999` отсутствует в организациях;
- город `city_id=110` не связан с организацией;
- в источнике транзакций есть повторяющаяся строка.
